      C64 Visual Assembler
      
      
      v1.4.4
      
      
      A visual block-based 6502 assembler for the Commodore 64.
      Build programs by dragging and
        dropping instruction blocks.
      
      
      © 2026 Zsolt Tarczali
      
      
      retroboj@outlook.com
      
      
    
      
        

  
    
      
      
      What's New
      
      
      v1.5.1
      
      
        
        
      • 
          Bug fixes & UI improvements — "New program" now shows a confirmation dialog before clearing. STRING and RAWTEXT descriptions corrected (screen codes, not PETSCII). Tonns of other small fixes.
        
        • 
        
      • 
          Export to D64 — assemble your program and export it directly to a .d64 disk image using VICE's c1541 tool. Add extra files (data, sprites, PRGs) to the same disk before export.
        
        • 
        
      • 
          Run via D64 — new split run button lets you choose between running as a plain PRG or packaging into a D64 and launching VICE directly from the disk image.
        
        • 
        
      • 
          LOADFILE macro — load a file from a D64 at runtime using C64 KERNAL SETNAM/SETLFS/LOAD routines. Supports optional override address and error-label (BCS) for error handling.
        
        • 
        
      • 
          LOADFILE demo sample — a ready-to-run example that loads DEMO-COLORS.PRG from a D64 at runtime and then cycles border and background colors.
        
        • 
        
      • 
          Run on hardware (C64 Ultimate) — send and run your assembled PRG directly on a 1541 Ultimate / Ultimate 64 device via its REST API. Configure host and password in Hardware Settings.
        
        • 
        
      • 
          OLED theme — a new pure-black OLED theme for AMOLED screens. Select it from the new theme picker (Light / Dark / OLED).
        
        • 
        
      • 
          D64 metadata in projects — disk name, program name, and extra file list are now saved into the project JSON so they are restored when the project or sample is reloaded.
