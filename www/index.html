    What's New
    
      
    v2.5.8
    
      
      
        
    • 
          New: Version control: the project snapshots became a git-like version control — commits with a message and a short hash, a log with HEAD, Diff against the working copy (Block-mode programs are compared as assembly lines, so JSON projects show readable changes), Checkout into the editor and separate autosave entries. Works on Block, Expert and Ultimate Basic tabs.
        
      • 
        
    • 
          New: Git integration: choose git.exe in Settings → Version control (or auto-detect). Inside a git repository the dialog shows the branch, the changed files, commit (saves first), log, diff with a RAW view, checkout, Pull / Push and git init.
        
      • 
        
    • 
          New: Report Bug: a built-in report form with up to 4 screenshots (file, Ctrl+V or drag and drop), an optional email, system info and the recent app errors.
        
      • 
        
    • 
          Professional serial by email: supporters request their serial in the registration dialog; the Professional version can be bought on c64va.pro with PayPal (5 €, one-time) and the serial arrives by email right after the payment.
        
      • 
        
    • 
          SID Player: Shuffle and per-tune favourites (★), kept in the saved state and in .sidpl playlists.
        
      • 
        
    • 
          From 2.5.7: VA SID Core 1.2: the SID Player now runs tunes on a cycle-exact 6510 (every bus cycle, dummy accesses, VICE's interrupt timing), CIA 6526A timers / interrupts / TOD, VIC-II timing with bad lines, sprite DMA and raster interrupts, and the 6510 I/O port.
        
      • 
        
    • 
          From 2.5.7: Hi-Res Editor: two colours in every 8×8 cell: the new Cell paper tool sets the background of each cell (the low nibble of its screen RAM byte), so every cell can have its own ink and paper. The eraser now uncovers the cell's own background.
        
      • 
        
    • 
          From 2.5.7: Exact C64 character ROM: the ROM viewer, Load ROM in the Character Editor and the Map / Level editors now use the real glyphs (checked byte by byte against the 901225-01 character ROM); several graphics characters were wrong or missing before.
        
      • 
        
    • 
          From 2.5.7: Sprite Editor: a hi-res overlay sprite over each frame (outline over a multicolor body), flood fill, select / move, rotate 90°, Mirror all (a mirrored copy of the animation), sprite sheet import with OKLab colour matching and dithering, a hitbox per frame with a table export, an X / Y ×2 preview and zoom up to 40×.
        
      • 
        
    • 
          From 2.5.7: Level Editor: an objects layer (start, enemies, items, doors, exit, triggers → LEVEL_OBJ_* tables), character attributes (solid, ladder, hazard, collectible → LEVEL_ATTR), an edge check between screens, colours per screen, a memory meter with RLE export and unpacker, and Run in VICE — a joystick-scrolled test program built from the level.
        
      • 
        
    • 
          From 2.5.7: Character Editor: undo / redo, drawing tools (pencil, line, rectangle, fill), rotate 90°, copy / paste and drag to swap characters on the map (Shift+drag copies), 2×1 / 1×2 / 2×2 tiles edited as one picture, the lowercase ROM set, a text preview and range export (.bin or .byte lines). The Charset Canvas zooms 2×–24× (slider or Ctrl+wheel) with a pixel grid, sets the background in hi-res mode too, and can switch single characters to hi-res inside multicolor mode (Color RAM bit 3), like the C64, and has an ECM mode with a background ($D021–$D024) per character.
        
      • 
        
    • 
          From 2.5.6: SID Player: a toolbar button opens a floating player for .sid (PSID / RSID) tunes — a playlist with drag and drop, previous / next tune, subtunes, seek and ±10 s, volume, and playlist save / open (.sidpl). The list and the window are remembered.
        
      • 
        
    • 
          From 2.5.6: VA SID Core 1.1: a built-in SID emulation (MOS 6581 / 8580, reSID-aligned 6581 filter) with a cycle-locked PSID / RSID player, so raster-IRQ and digi tunes play too. Choose it in Settings → SID preview; the player shows which engine is playing.
        
      • 
        
    • 
          From 2.5.6: SID Editor: knobs for the instrument parameters, a wider ADSR graph, MIDI input with an activity lamp, recording into the tracker (a new pattern is added when the current one is full), a metronome with beat lamps, pattern delete, the master volume on VA-VK, and Import GoatTracker .sng.
        
      • 
        
    • 
          From 2.5.6: Freemium and Professional: without a registration the app runs as Freemium. Enter the email address and serial from your purchase in Menu → Register… for the Professional version with every editor, build and run option, language and theme.
        
      • 
        
    • 
          From 2.5.7: Ultimate Basic 1.6.4 bundled.
