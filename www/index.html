    C64 Visual Assembler
    
      
    v1.6.0
    
      
    A visual block-based 6502 assembler for the Commodore 64.
    Build programs by dragging and
        dropping instruction blocks.
    
      
    © 2026 Zsolt Tarczali
    
      
    retroboj@outlook.com
    
      
    
    
      

  
    
    
      
    What's New
    
      
    v1.6.0
    
      
      
        
    • 
          Expert Mode — a full direct-text ASM editor alongside the block editor. Write 6502 assembly by hand with live syntax highlighting, real-time disassembly panel, block-mode palette sync, and a built-in source formatter. Switch between Block and Expert mode per-tab at any time.
        
      • 
        
    • 
          Tab bar & project panel — open multiple programs in tabs. Each tab has its own program state and dirty indicator. The Expert mode project panel lets you manage multi-file .proj projects.
        
      • 
        
    • 
          charOffset for TEXT / STRING macros — an optional byte offset added to every screen-code character. Use $80 for reverse-video text.
        
      • 
        
    • 
          JSR to inline macros — JSR macroName now resolves correctly when the target is an inline .macro definition. The macro body is emitted as a real subroutine at its declared position.
        
      • 
        
    • 
          UI polish — Apple-style toggle switches, animated run-mode dropdown, animated settings menu, 8 px border-radius on panels and memory strip, improved OLED theme brightness, full-width operand dropdown.
        
      • 
        
    • 
          Bug fixes — disassembler no longer shows [error] after .include blocks; file extension now shown in tab bar after save/load; expert editor no longer clips code on the right and bottom edges.
