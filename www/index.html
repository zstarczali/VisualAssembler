    C64 Visual Assembler
    
      
    v1.4.1
    
      
    A visual block-based 6502 assembler for the Commodore 64.
    Build programs by dragging and
        dropping instruction blocks.

    What's New
    
      
    v1.4.1
    
      
      
        
    • 
          REGION / ENDREGION blocks — group any set of blocks into a named,
          collapsible section. Click the toggle to fold the entire region into one line.
          Includes Expand all and Select in ASM buttons.
          ENDREGION shows the matching region name. Supports nested regions.
          Generates zero bytes — purely visual, no effect on the assembled output.
        
      • 
        
    • 
          #<label / #>label operand support — lo/hi byte operators now work in
          immediate mode (e.g. LDA #<irq_handler / LDA #>irq_handler).
          Essential for setting up IRQ handlers and splitting 16-bit addresses.
        
      • 
        
    • 
          Report Bug — new menu item. Opens the default mail client with
          VA version and OS pre-filled in the message body.
        
      • 
        
    • 
          10 PRINT sample — classic one-liner maze using raster counter $D012
          as a random source to alternate between CHR$(205) and CHR$(206) via KERNAL CHROUT.
        
      • 
        
    • 
          Raster IRQ demo — new sample program. Sets up a VIC-II raster interrupt
          at line $80, increments a frame counter in $FB each IRQ and writes
          the lower 4 bits to $D020 / $D021, cycling through all 16 C64 colors.
        
      • 
        
    • 
          Overlapping raster bars demo — new sample program. A classic C64 raster
          effect: a static rainbow bar (ras1start) has a scrolling silver bar
          (ras2start) overlaid on it each frame. The IRQ renders 80 raster lines
          per frame using a double-read LDA $D012 / CMP $D012 raster-wait technique,
          and updates the color tables every 3rd frame via the checkspeed /
          movesilver / backup + copysilver routine chain.
        
      • 
        
    • 
          Stability fixes —
          VICE not configured now shows a clear error toast instead of silently failing.
          Sample selector no longer resets to the first item when loading a project file.
          Label picker dropdown position corrected in CRT retro mode.
          Startup white flash reduced (window background color matches the app).
