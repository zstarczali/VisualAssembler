        What's New
        
      
        v2.8.6
        
      
          
        
        • 
          Detailed wave table steps: a step of the SID Editor's wave / arpeggio table can have its own length, pulse width and filter (cutoff, resonance, mode, routed voices), under the … button of the step, and a table can have 64 steps. The exported 6502 player plays them. Files with such steps need 2.8.6 or later.
        
          • 
        
        • 
          Speech in .sid import: speech and other sounds that step the waveform, pulse width and filter from frame to frame (GoatTracker tables) come in as such steps, so they sound like the original. GoatTracker's hard restart is recognized too.
        
          • 
      
        
      
        v2.8.5
        
      
          
        
        • 
          Shared SID emulation: VA SID Core, reSID and the cycle-exact C64 behind the SID Player and the SID Editor now come from one library, va-sid, which VA SID Studio uses too, so both apps play every tune the same way. The sound does not change.
        
          • 
        
        • 
          About: the About window shows the VA-SID version next to UltimateBasic, VMA and R65.
