    What's New
    
      
    v2.3.7
    
      
      
        
    • 
          New: Undo / Redo and multi-block editing — toolbar history controls restore block-program changes per tab. Select ranges or multiple blocks, then copy, cut, paste, duplicate or delete them as one operation; region groups remain intact.
        
      • 
        
    • 
          New: Breakpoints in Block, Expert and Ultimate Basic modes — set breakpoints from block cards or editor line-number gutters. Breakpoints are stored per tab and resolved to the exact executable address before RetroDebugger starts.
        
      • 
        
    • 
          Improved: RetroDebugger integration — the external debugger replaces the limited embedded Ultimate Basic debugger, and all three editor modes now launch it with source maps, labels and breakpoint files. Existing instances receive new tasks via -pass; BASIC SYS programs use -autojmp, while plain PRGs use their real load address with -jmp.
        
      • 
        
    • 
          New: BASIC stub visibility — a VA-style setting can show the real BASIC SYS stub at $0801 in Disassembler and Monitor outputs. Block, Expert and Ultimate Basic modes share the same build-accurate code origin.
        
      • 
        
    • 
          New: Ultimate Basic Monitor view — inspect compiler-generated machine code and the optional BASIC stub as a memory dump beside the UB editor, with a dedicated toolbar button and a non-wrapping, resizable output panel.
        
      • 
        
    • 
          Fixed: Debugger, disassembler and label addresses — plain PRGs now use the load address stored in their PRG header, project startup files keep their own macro and source context, and .dbg, .sym and VICE label sidecars stay aligned with generated code.
        
      • 
        
    • 
          Fixed: Editor caret and line alignment — Ultimate Basic formatting preserves the selection, and caret tracking now survives blank lines, held cursor keys and minimap boundaries; UB line numbers scale without clipping. Expert line numbers and source rows use a shared integer-pixel line height to prevent vertical drift.
