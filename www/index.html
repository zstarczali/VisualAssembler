    C64 Visual Assembler
    
      
    v2.1.7
    
      
    A visual block-based 6502 assembler for the Commodore 64.
    Build programs by dragging and
        dropping instruction blocks.
    
      
    © 2026 Zsolt Tarczali
    
      
    retroboj@outlook.com
    
      
    
    
      

  
    
    
      
    What's New
    
      
    v2.1.7
    
      
      
        
    • 
          Hotfix (2.1.7) — MEMCPY and MEMSET blocks in Block mode now show the little dropdown arrow on their input fields (source / destination / value / size), matching every other macro block. The label/const picker itself already worked; only the visual chevron was missing.
        
      • 
        
    • 
          Custom tooltips everywhere — all remaining UI buttons (project file star & delete, tab close/new, block action buttons, collapse toggle) now use the custom CSS aria-label tooltip instead of the flaky native browser tooltip, consistent with the rest of the toolbar.
        
      • 
        
    • 
          Auto-snapshot toggle — Hardware Settings has a new Snapshot section with a checkbox to enable or disable automatic project snapshot creation. Previously the 2.5-second auto-save ran unconditionally; now you can turn it off if snapshots are not needed.
        
      • 
        
    • 
          Dark mode scrollbars — macOS native scrollbars now appear dark in Dark and OLED themes (WKWebView color-scheme: dark fix). Previously the scrollbars were always light-themed regardless of the app theme.
        
      • 
        
    • 
          Hotfixes (2.1.5) — Expert-mode asset loading, compile error clarity, syntax highlighting for previously missing macros, missing-file validation for .include / .incbin / .sid in both modes, unknown-directive detection, cleaner runtime IF / WHILE / UNTIL / INVOKE error messages, and broader localized compile error coverage across HU / EN / ES / DE.
        
      • 
        
    • 
          Expert asset auto-reload — typing .include, .incbin, or .sid directly in Expert mode now loads the referenced file automatically, resolving names against the working folder and the bundled samples/ directory.
        
      • 
        
    • 
          Hotfixes — this 2.1.5 release bundles the recent Expert-mode and compile-time fixes, including asset loading, compile error clarity, syntax highlighting for previously missing macros, missing-file validation for .include / .incbin / .sid in both modes, unknown-directive detection, cleaner runtime IF / WHILE / UNTIL / INVOKE error messages, and broader localized compile error coverage across HU / EN / ES / DE.
        
      • 
        
    • 
          Missing-file guard — empty or omitted filenames on .include, .incbin, and .sid now surface as clear errors in Expert and Block mode instead of silently compiling to nothing.
        
      • 
        
    • 
          Unknown directive detection — Expert mode no longer swallows typos like .notarealthing as comments; unknown directives fail the compile with a targeted error.
        
      • 
        
    • 
          Clearer runtime errors — missing .endif, .endw, .repeat, or unresolved INVOKE targets now emit user-friendly, localized messages instead of leaking internal auto-generated label names.
        
      • 
        
    • 
          Expert toolbar — new button collapses or expands every .region in one click; the region caret position is preserved when switching from Expert back to Block mode.
        
      • 
        
    • 
          Syntax highlighting — .for, .endf, .mouse, .exodecrunch, .reu_*, .turbo_*, and .supercpu_detect are now colored in the Expert editor.
        
      • 
        
    • 
          Hardware settings dialog — long Exomizer, RetroDebugger, and VICE paths no longer force a horizontal scrollbar; the status line truncates with an ellipsis and shows the full path on hover.
        
      • 
        
    • 
          Expert editor fix — Expert mode now keeps the typed text, highlight overlay, error lines, and caret position aligned even when multiple compile errors are present.
        
      • 
        
    • 
          Compile dialog fix — the compile error dialog now keeps the selected entry highlighted, uses a proper pointer cursor, and jumps to the matching Expert mode line without closing the dialog.
        
      • 
        
    • 
          Expert region folding fix — collapsed .region blocks now really hide their body in Expert mode without leaving giant blank gaps, while caret placement, line numbers, tab switching, formatting, and save/load keep using the full source correctly behind the scenes.
        
      • 
        
    • 
          Region selection toggle — Expert mode still has a toolbar button that turns the automatic region highlight on or off without changing the actual fold state.
