NEW IN V2.3.9
// A REAL ASSEMBLER FEEL

EXPRESSIONS, LOCAL LABELS
AND LONG BRANCHES

Version 2.3.9 brings the quality-of-life syntax that power users expect from 64tass, ACME and Kick Assembler — usable in Expert-mode text and, where it makes sense, as blocks.

►
* in any expression — the program counter now works inside operand expressions, not just alone: BNE *-5, JMP *+20, LDA #<*, LDA #>(*+63). A * after a value (STRIDE*2) is still multiplication.
►
Local (dotted) labels — .loop is scoped to the nearest preceding global label, so DrawSprite and ClearScreen can each have their own .loop without a clash.
►
Long-branch pseudo-ops — LBNE, LBEQ, LBCC, LBCS, LBMI, LBPL, LBVC, LBVS assemble to an inverted branch over a JMP (5 bytes) so the target can be any distance away.
►
.assert directive — .assert end - start <= 256, "message" is checked at assembly time and fails the build (with the actual value) when it is false.
►
Self-modifying-code labels — LDA value:#$00 puts the label value on the operand byte, so STA value patches it — no instruction+1 label needed.
►
Friendlier branch errors — an out-of-range branch reports exactly how far it overshoots and suggests the matching LBxx long branch.

// CARTRIDGE EXPORT

BUILD CRT
MAGIC DESK 64K CARTRIDGE

One click and your program becomes a Commodore 64 cartridge image. Menu → Build → Build CRT packs the current tab into a Magic Desk (type 19) .crt file with 8 × 8 KB banks and a small bank-0 loader that copies the payload into RAM and jumps to the entry point. Nothing else to configure.

►
All three modes — works from block mode, Expert mode and Ultimate Basic mode.
►
Up to 64K payload — 8 banks × 8 KB, max 65 408 bytes after the loader header.
►
Widely compatible — runs on VICE, TheC64, EasyFlash, Kung Fu Flash, 1541 Ultimate II+ and Ultimate 64.
►
Any origin — the loader honours the PRG load address, so $0801, $C000 and multi-ORG builds all work.
►
Safe cart-off exit — an 8-byte exit stub is copied to $0100 so unmapping the cartridge cannot interrupt the fetch.
