// DATA WE PROCESS

Website visits

Like every web server, our hosting provider records technical access logs (IP address, time, requested page, browser). They are used for operation and security and are kept as long as the hosting provider's log retention. Legal basis: legitimate interest (Art. 6(1)(f) GDPR).

Download counts are stored per day and file, without any personal data.

The documentation reader loads two open-source libraries (marked, DOMPurify) from the jsDelivr CDN, which therefore sees your IP address.

Serial requests (older app versions)

Up to version 2.5.9 the app had a Professional serial. If you requested one, we store your email address, the serial, the language, the time, the IP address and the browser of the request, so the serial can be sent again. Legal basis: your request (Art. 6(1)(b) GDPR). From version 2.6.0 no serial is needed; you can ask for this data to be deleted.

Support chat in the app

When you write to us in the app (Menu → Support), we store your messages and the files you attach, your name, the optional email address, the app version, operating system, UI language, the country looked up from your IP address in our local database and the app's random install ID that links the conversation. The IP address is kept for at most one day, only to limit abuse. The messages are used only to answer you; replies may also be sent to the email address you gave. Legal basis: your request (Art. 6(1)(b) GDPR). You can ask for the conversation to be deleted at any time.

Bug reports from the app

When you send a bug report from the app (Menu → Report Bug), we store what you entered (summary, description, optional email address, screenshots), the system information you chose to include (app version, operating system, language, screen size, recent app errors) and the IP address of the request. It is only used to fix the problem and to reply to you. Legal basis: your voluntary submission (Art. 6(1)(a) GDPR). Reports are deleted when they are no longer needed for fixing the issue; you can ask for earlier deletion.

Anonymous usage statistics in the app (from version 2.6.0)

At most once a day, at startup, the app sends: a random install ID (created on your computer, stored in the app's config.json as launchPing), the app version, the operating system, the UI language, the number of launches and the active minutes since the last ping (a minute counts while the window is visible and there was mouse or keyboard input in the last 5 minutes), and whether a serial from versions 2.5.6–2.5.9 is still stored (only yes / no). From the IP address of the request the country is looked up in a local database on our own server (IP to Country Lite by DB-IP) and only the two-letter country code is stored; the IP address itself is not stored and not sent anywhere. No email address, serial, project or source code is sent. The app also asks the website for short messages (for example about a new version, sometimes only for supporters), sending the version, operating system, language, the same yes / no and the same install ID, so we can count how many installs received a message; this request also updates the time the install was last seen.

Legal basis: legitimate interest in knowing how many people use which version and platform (Art. 6(1)(f) GDPR). To object, block the app's network access to c64va.pro or contact us with your install ID, and we delete its records.

Donations and external links

The support buttons lead to PayPal; links lead to GitHub, Facebook, LinkedIn and itch.io. These services process data under their own privacy policies. We only receive what PayPal shows us about a payment.
