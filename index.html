What's New

    
v1.1.6

    
    
      
  • 
        BASIC SYS stub toggle — added checkbox in Settings menu to enable/disable BASIC SYS stub generation. When disabled, programs load at $C000 (Free RAM) instead of $0801. Warning: sample programs with RAWBYTES, sprites, or fixed memory addresses may not work correctly without the stub.
      
    • 
      
  • 
        Current file indicator — the loaded project filename now appears in the ASM panel header for better context. Shows which file you're currently working on, disappears when loading samples or clearing the program.
      
    • 
      
  • 
        Splash screen — added animated loading screen on application startup with smooth fade-out transition (2 seconds).
      
    • 
      
  • 
        UI improvements — fixed checkbox focus outline styling to prevent oversized focus rectangles, improved visual feedback for form controls, better panel header layout.
      
    • 
      
  • 
        Bug fixes — fixed PRG generation when BASIC SYS stub is disabled, corrected origin address handling for non-standard load addresses, improved file path handling in status messages.
